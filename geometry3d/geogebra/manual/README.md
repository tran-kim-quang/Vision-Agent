# Official command documentation snapshot

`commands.json` contains original English AsciiDoc pages from
[geogebra/manual](https://github.com/geogebra/manual). Each page retains its
original syntax, examples and notes. Snapshot metadata records the upstream
repository, source directory, language and exact commit. Retrieval responses
include both the published documentation URL and the immutable source URL.

Generated by `scripts/sync_geogebra_docs.py`; do not edit the corpus manually.
See the project README for retrieval behavior and update commands. The snapshot
is reference data, not a list of operations implemented by the local compiler.
